# Divine Ascension

Divine Ascension is a Minecraft plugin that allows players to experience the power and grandeur of a god. With this plugin, players can toggle god mode, summon powerful weapons, and access a GUI with various god powers and weapons. The plugin is designed to enhance the gameplay experience by providing unique abilities and items that players can use to dominate the game world.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. To toggle god mode, use the command `/godmode`.
2. To summon a god weapon, use the command `/summonweapon`.
3. To access the god powers and weapons GUI, use the command `/godgui`.
4. In the GUI, click on the items to activate their respective powers or summon the weapons.
